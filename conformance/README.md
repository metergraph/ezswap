# Conformance fixtures

These files pin the statistics, sentences and prices in this repository to
what Metergraph's hosted product computes for the same inputs. Each was
generated by running Metergraph's implementation on synthetic inputs. They
hold no real traces, prompts or outputs.

Do not edit the expected values by hand. If a test here fails, the code moved
a number: fix the code. If you believe a fixture itself needs to change, open
an issue; maintainers regenerate the fixtures from Metergraph's
implementation.

| File | Pins |
|---|---|
| `experiment_equivalence.json` | `equivalence()` for a run without a noise floor, and the formatters |
| `experiment_equivalence_floor.json` | `equivalence()` with a noise floor |
| `summarize.json` | the per-arm summary and the rules it is built from: JSON parsing, cut off, empty or refused, cached input, output facts |
| `noise_floor.json` | `noiseFloorView()`, field kinds and list overlap |
| `page.json` | stat rows, spreads, floor readings, sentences, the summary table, bootstrap ranges and the field tree, for three views; one view is built by this repository's `buildView` from the synthetic run in the file, which the tests also rebuild |
| `pricing.json` | the cost of a call from the price catalog: aliases, cache-inclusive and exclusive input, long context, effective dates. Regenerated by `scripts/build_pricing_conformance.py` from metergraph-core, at the same commit as `internal/pricing/prices.json` |
| `estimate.json` | the run estimate and each call's upper-bound reservation |

The tests that read them are in `internal/core` (`conformance_test.go`,
`page_test.go` and others) and `internal/pricing` (`catalog_test.go` and
`estimate_test.go`).
